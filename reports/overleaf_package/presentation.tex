\begin{frame}{Motivation}
  \begin{itemize}
    \item LLM evaluation is often summarized as a static leaderboard.
    \item That implicitly assumes the rank order is stable under reasonable evaluation choices.
    \item But benchmark results depend on at least two sources of variation:
    \begin{itemize}
      \item prompt wording and formatting
      \item which subset of examples happens to be evaluated
    \end{itemize}
    \item Our question is not only ``who scores highest,'' but ``how robust is the ranking itself?''
  \end{itemize}
\end{frame}

\begin{frame}{Related Work and Gap}
  \begin{itemize}
    \item Benchmark papers such as MMLU, ARC, and HellaSwag define widely used evaluation settings.
    \item Prompt-robustness work shows that LLM behavior can change under task-preserving prompt variation.
    \item Reliability discussions in LLM evaluation argue that benchmark scores are properties of both models and protocols.
    \item The missing piece is ranking stability:
    \begin{itemize}
      \item do small protocol changes only move scores,
      \item or can they actually flip model order?
    \end{itemize}
  \end{itemize}
\end{frame}

\begin{frame}{Our Idea}
  \begin{block}{Core framing}
    Treat leaderboard rank as a random variable induced by evaluation protocol choices.
  \end{block}

  \begin{itemize}
    \item We perturb prompts without changing task semantics.
    \item We bootstrap the evaluation subset to model sample-composition noise.
    \item We then ask whether the induced ranking changes.
  \end{itemize}

  \[
  r_{d,p,b}(m) = \text{rank of model } m
  \]
  \[
  \text{RRR}_{d,p} = \Pr\left(r_{d,p,b} \neq r_{d,\text{minimal},b}\right)
  \]

  \begin{itemize}
    \item RRR = Ranking Reversal Rate
    \item High RRR means a single leaderboard is not a stable summary
  \end{itemize}
\end{frame}

  \begin{columns}[T]
    \begin{column}{0.55\textwidth}
      \begin{itemize}

        \begin{itemize}

        \end{itemize}
        \item Total question pool: 900
        \item Prompt templates: 4
        \item Prompt requests: 3600
        \item Models: 4
        \item Responses collected: 14400
      \end{itemize}
    \end{column}
    \begin{column}{0.45\textwidth}
      \begin{itemize}
        \item Models:
        \begin{itemize}

          \item Gemini-2.0-flash
          \item Qwen-2.5-7B
          \item Llama-3.1-8B
        \end{itemize}
        \item Inference:
        \begin{itemize}
          \item temperature = 0
          \item max\_tokens = 150
        \end{itemize}
        \item Analysis:
        \begin{itemize}
          \item 2000 bootstrap resamples per dataset
          \item accuracy, CI, pairwise difference, RRR
        \end{itemize}
      \end{itemize}
    \end{column}
  \end{columns}
\end{frame}

\begin{frame}{Implementation Pipeline}
  \begin{enumerate}
    \item Sample benchmark questions and generate 4 prompt templates per item.
    \item Query 4 models through OpenRouter.
    \item Parse outputs into \texttt{A/B/C/D} and score automatically.
    \item Bootstrap each dataset 2000 times.
    \item Compare prompt-specific rankings against the minimal prompt baseline.
  \end{enumerate}

  \vspace{0.8em}
  \begin{block}{Why this pipeline matters}
    It isolates two realistic sources of leaderboard instability: prompt design and subset choice.
  \end{block}
\end{frame}

    \begin{column}{0.38\textwidth}
      \textbf{RRR relative to the minimal prompt}
      \vspace{0.6em}

      \begin{itemize}
        \item ARC: 4.70\%, 1.65\%, 1.05\%
        \item MMLU: 19.60\%, 8.05\%, 13.50\%
        \item HellaSwag: 62.55\%, 41.35\%, 38.50\%
      \end{itemize}

      \vspace{0.6em}
      \textbf{Message:}
      A single leaderboard can be very stable on one benchmark and very fragile on another.
    \end{column}
  \end{columns}
\end{frame}

  \vspace{0.8em}
  \begin{itemize}
    \item Ranking reversals happen most often when model gaps are narrow.
    \item Confidence intervals on accuracy are useful, but rank robustness is the sharper question.
  \end{itemize}

\begin{frame}{Takeaways}
  \begin{itemize}
    \item Static leaderboards should not be interpreted as universally stable facts.
    \item Prompt perturbations and subset resampling can change rank order, especially when models are close.
    \item ARC is robust, MMLU has a stable winner but unstable middle, and HellaSwag is highly fragile.
    \item A better evaluation practice should report:
    \begin{itemize}
      \item average accuracy,
      \item uncertainty intervals,
      \item and ranking stability metrics such as RRR.
    \end{itemize}
  \end{itemize}

  \vspace{0.8em}
  \begin{block}{One-sentence conclusion}
    The question is not only who is best on average, but whether that ordering survives reasonable evaluation variation.
  \end{block}
\end{frame}
