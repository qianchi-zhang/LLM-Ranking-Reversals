Do LLM Rankings Change if You Ask Differently?

A keynote-style presentation about ranking reversals under non-semantic prompt perturbations and subset resampling.

ZHANG / PENG / JIANG / MENG
The Setup

A leaderboard feels definitive.

What a leaderboard suggests

Model A: 89.2%
Model B: 87.3%

So A > B.

What we ask instead

  • What if we phrase the same task differently?
  • What if the evaluation subset changes?
  • Does the ranking still survive?
Motivation

Our target is not only score. It is ranking reliability.

Static

Leaderboards are compact, but they silently assume stable rank order.

Prompt

Wording changes can alter how a model enters the task.

Subset

Small model gaps can flip when the evaluated items change.

Research Gap

Prior work studies prompt sensitivity. We study whether it flips the ordering.

Benchmarks

MMLU, ARC, and HellaSwag define the task settings and scoreboards people trust.

Prompt robustness

Existing work shows non-semantic prompt changes can move model behavior.

Our gap

Do those shifts merely change scores, or do they actually reverse the rank order?

Method

Treat rank as a random outcome induced by evaluation choices.

  • Keep task semantics fixed.
  • Perturb prompts in a task-preserving way.
  • Bootstrap the evaluation subset.
  • Measure whether the ranking changes.

Key metric

RRR = Probability that the ranking differs from the baseline ranking

RRR: Ranking Reversal Rate
