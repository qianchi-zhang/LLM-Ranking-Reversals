# Reports and Presentation Index

This directory contains the repository's written outputs, final report sources, and presentation materials.

## Canonical deliverables

- `final_report/final_report.tex`: canonical final report source
- `overleaf_package/presentation.tex`: canonical Beamer presentation source
- `web_presentation/index.html`: canonical HTML presentation

## Subdirectories

- `final_report/`: course final report sources, figures, and archived report variants
- `overleaf_package/`: Overleaf-ready report and presentation package
- `web_presentation/`: HTML slide deck and assets

## Markdown analysis outputs

- `analysis_summary.md`: concise analysis summary
- `focused_research_question_discussion.md`: focused discussion draft
- `conference_style_report_en.md`: English conference-style markdown report
- `conference_style_report_zh.md`: Chinese conference-style markdown report
- `mmlu_subject_bootstrap_summary.md`: earlier MMLU subject summary
- `mmlu_subject_bootstrap_summary_expanded.md`: expanded MMLU subject summary

## Packaged artifacts

- `overleaf_package.zip`: upload-ready Overleaf bundle
- `web_presentation.zip`: packaged HTML presentation

## Notes

- Files under `final_report/archive/` are kept for reference only and are not the default source of truth.
- If a report file conflicts with the current pipeline, prefer `run_pipeline.py`, `src/`, and the generated artifacts under `data/` and `plots/`.
